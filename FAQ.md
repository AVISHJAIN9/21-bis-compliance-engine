# Frequently Asked Questions: BIS & AIS Statutory RAG Engine

### 1. What is BIS & AIS Statutory RAG Engine?
Statutory compliance and standards retrieval engine using FastEmbed ONNX embeddings and FAISS vector indexing.

### 2. What technology stack does it use?
Built with Python (FastAPI, ONNX, FAISS), Vanilla JavaScript / HTML5.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/21-bis-compliance-engine/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
