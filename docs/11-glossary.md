# Step 12: Technical & Regulatory Glossary

This glossary defines every regulatory, machine learning, and software engineering term used across the **21-BIS-Compliance-Engine**.

---

## 1. Regulatory & Statutory Terms

- **BIS (Bureau of Indian Standards)**: The National Standards Body of India established under the *Bureau of Indian Standards Act, 2016*, responsible for formulating Indian Standards and administering product certification schemes.
- **QCO (Quality Control Order)**: A statutory order issued by an Indian central ministry under Section 16 of the *BIS Act, 2016*, making compliance with a specified Indian Standard legally mandatory for manufacture, import, distribution, or sale.
- **Scheme-I (ISI Mark Certification)**: The premier conformity assessment scheme administered by BIS under which manufacturers are granted a license to use the official Standard Mark (ISI Mark) upon satisfying in-house testing equipment, factory quality control, and laboratory test criteria.
- **AIS (Automotive Industry Standards)**: Technical automotive safety standards formulated by the Automotive Industry Standards Committee (AISC) and mandated under the *Central Motor Vehicles Rules (CMVR)*.
- **CMVR Rule 126**: The statutory regulation under the *Central Motor Vehicles Rules, 1989* requiring manufacturers of motor vehicles and automotive safety components to submit prototypes to authorized testing agencies for Type Approval Certification.
- **Homologation**: The formal government approval process certifying that an automotive vehicle or component complies with all mandatory safety, environmental, and performance standards before entering commercial production.
- **TAC (Type Approval Certificate)**: An official certificate issued by an accredited agency (ARAI, ICAT, CIRT) confirming that an automotive prototype complies with CMVR and AIS standards.
- **COP (Conformity of Production)**: A periodic surveillance audit (mandated under AIS-037) where random production units are drawn from assembly lines to verify ongoing adherence to approved homologation blueprints.
- **SIT (Scheme of Inspection and Testing)**: An official regulatory schedule issued by BIS detailing the minimum sampling frequencies, test apparatus, testing procedures, and record-keeping registers required in the factory laboratory.
- **NABL (National Accreditation Board for Testing and Calibration Laboratories)**: The constituent board of the Quality Council of India that formally accredits calibration and testing laboratories to international ISO/IEC 17025 standards.
- **Manakonline Portal**: The official digital portal operated by the Bureau of Indian Standards for submitting Scheme-I license applications, uploading test reports, and tracking surveillance audits.
- **DPIIT**: Department for Promotion of Industry and Internal Trade under the Ministry of Commerce and Industry, which issues QCOs for general consumer goods, cement, and toys.
- **MoRTH**: Ministry of Road Transport and Highways, the central government ministry administering the CMVR and AIS automotive standards.

## 2. Machine Learning & Vector Search Terms

- **Dense Vector Embedding**: A fixed-length array of continuous floating-point numbers (here, 384 dimensions) generated by a neural network, encoding semantic meaning such that semantically related concepts are geometrically close in vector space.
- **FAISS (Facebook AI Similarity Search)**: An open-source C++ library developed by Meta AI optimized for high-speed similarity search and nearest-neighbor clustering in dense vector collections.
- **`IndexFlatIP`**: An exact FAISS index that calculates inner products (dot products) between query vectors and corpus vectors. When vectors are unit-normalized ($L_2=1$), inner products are identically equal to cosine similarity.
- **Cosine Similarity**: A metric measuring the cosine of the angle between two multi-dimensional vectors, ranging from $-1.0$ (opposite) to $+1.0$ (identical).
- **FastEmbed**: A lightweight Python library for generating transformer embeddings via Microsoft ONNX Runtime without requiring PyTorch or CUDA dependencies.
- **ONNX (Open Neural Network Exchange)**: An open format representing machine learning models that enables execution via optimized runtimes (ONNX Runtime) across heterogeneous hardware architectures (x86, ARM, CPU, GPU).
- **RAG (Retrieval-Augmented Generation)**: An architectural pattern that retrieves relevant, grounded factual documents from an external index to answer user queries, eliminating hallucination risks.
- **Domain Guardrail**: A programmatic safety filter combining rule-based heuristics (regex, keyword blacklists) and mathematical vector thresholds to block out-of-domain or non-statutory prompts.
- **Joblib**: A set of tools in Python providing lightweight pipelining and disk serialization for Scikit-Learn machine learning estimators.

## 3. Web & Systems Engineering Terms

- **ASGI (Asynchronous Server Gateway Interface)**: The modern Python asynchronous web server specification succeeding WSGI, enabling concurrent handling of HTTP, WebSockets, and background tasks.
- **FastAPI**: A modern, high-performance web framework for building REST APIs with Python 3.8+ based on standard Python type hints and Starlette.
- **Uvicorn**: A lightning-fast ASGI web server implementation built on `uvloop` (an ultra-fast libuv event loop) and `httptools`.
- **Pydantic v2**: A data validation and settings management library written in Rust (`pydantic-core`) that enforces type annotations at runtime and provides automatic serialization.
- **CORS (Cross-Origin Resource Sharing)**: An HTTP-header based security mechanism allowing a server to specify which origins are permitted to access its resources from a web browser.
- **RFC 4180**: The authoritative Internet engineering specification standardizing the structure, escaping rules, and MIME type (`text/csv`) of Comma-Separated Values (CSV) files.
- **SPA (Single Page Application)**: A web application that loads a single HTML page and dynamically updates content as the user interacts, eliminating full-page browser reloads.
- **Vite**: A next-generation frontend build tool featuring an ultra-fast esbuild-powered dev server with instant Hot Module Replacement (HMR) and Rollup-based production bundling.
- **Air-Gapped**: A security and operational posture where a computer system or software application is completely isolated from the public internet and external network connections.
